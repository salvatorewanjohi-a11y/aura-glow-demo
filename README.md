# Aura Glow Spa & Salon – booking site demo

A demo of the Aura Glow Spa & Salon (TJ&U Fitness Complex, Rabai Road) WooCommerce booking site that runs entirely in the browser with WordPress Playground.

- Booking site: https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/aura-glow-demo/main/blueprint.json
- Store admin (treatments, prices, appointments): https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/aura-glow-demo/main/blueprint-admin.json

Each visit builds a fresh copy, so test appointments are not kept.
